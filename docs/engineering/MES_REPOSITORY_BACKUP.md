# MES 單站備份邊界

## 架構與程式邊界

MES 專題以自己的 MES 資料庫匯出與還原租戶業務資料；匯出、驗證、還原與 CSV 僅接受本 repository 的 `mes_` 領域表。身份、權限、稽核與冪等記錄不屬於可覆寫資料；其他系統表即使仍存在於共用 TypeScript schema 中，也不得查詢或接受其備份。參照驗證只使用 MES 表的關聯。既有跨站完整備份不自動轉換，須明確拒絕並由獨立遷移流程處理。

## 測試

先用新建隔離 MES SQLite 與實際備份函式驗證匯出、CSV、合法資料還原及其他系統表拒絕，並檢查備份表清單與新 MES schema 相符；遠端 CI 執行，不在本機測試。
